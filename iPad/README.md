# iPad + iPhone Setup

My iPad & iPhone extend my development setup when I am away from my computer. I connect to remote machines, use a mobile terminal, and keep Git repositories available locally.

## Development tools

- [Jump Desktop](https://jumpdesktop.com/) for remote desktop access to my PC.
- [Termius](https://termius.com/) for SSH and terminal access.
- [Working Copy](https://workingcopy.app/) for Git repositories on iPadOS & iOS.
- [a-Shell](https://holzschu.github.io/a-Shell_iOS/) for any SSH I need to complete.

## Setup order

1. Install Jump Desktop, Termius, and Working Copy from the App Store.
2. Configure Jump Desktop to connect to my remote computer and add SSH hosts to Termius.
3. Clone repositories in Working Copy and use its Git integrations when working away from my primary machine.
