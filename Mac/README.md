# Mac Setup

My Mac is my primary development machine **for work**. I set it up with a browser, editor, terminal, and AI-assisted development tools.

## Development tools

- [ChatGPT Codex](https://openai.com/codex/) for agentic coding work.
- [Claude Code](https://www.anthropic.com/claude-code) for working with projects from the command line.
- [Claude app](https://claude.ai/download) for desktop conversations and project work.
- [iTerm2](https://iterm2.com/) as my terminal application.
- [Visual Studio Code](https://code.visualstudio.com/) as my code editor.
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Node.js](https://nodejs.org/) + [NVM](https://github.com/nvm-sh/nvm)
- [Google Chrome](https://www.google.com/chrome/) for browsing and web development.

## Setup order

1. Install Chrome, iTerm2, and VS Code.
2. Sign in to ChatGPT Codex and Claude, then install and configure Claude Code.
3. Open projects in VS Code and use iTerm2 for terminal-based development and Git workflows.

## Non-Development Tools

- [OneNote](https://www.microsoft.com/microsoft-365/onenote/digital-note-taking-app) for notes
- [Microsoft Teams](https://www.microsoft.com/microsoft-teams/download-app) for chats and meetings
- [OneDrive](https://www.microsoft.com/microsoft-365/onedrive/online-cloud-storage) for files
- [Outlook](https://www.microsoft.com/microsoft-365/outlook/email-and-calendar-software-microsoft-outlook) for email
