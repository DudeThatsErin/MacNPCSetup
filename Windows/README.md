# Windows Setup

My Windows setup focuses on a lightweight development environment with an editor, shell, browser, and AI coding support.

## Development tools

- [Visual Studio Code](https://code.visualstudio.com/) as my code editor.
- [PowerShell](https://learn.microsoft.com/powershell/) as my command-line shell.
- [ChatGPT Codex](https://openai.com/codex/) for agentic coding work.
- [Microsoft Edge](https://www.microsoft.com/edge) for browsing and web development. It doesn't eat as much RAM as Chrome.

## Setup order

1. Install Edge updates, PowerShell updates, ChatGPT Codex, and VS Code.
2. Sign in to ChatGPT Codex.
3. Open projects in VS Code and use PowerShell for development and Git workflows (usually inside of VS Code).
